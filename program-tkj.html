Teknik Komputer Dan Jaringan

Bangun sistem, rakit jaringan, ciptakan solusi digital.

Tentang Program

Program Teknik Komputer dan Jaringan mempersiapkan siswa menguasai perangkat keras, instalasi jaringan, administrasi server, sekaligus asas pengembangan web dan aplikasi. Siswa belajar melalui proyek nyata: merancang topologi jaringan sekolah, membangun server, hingga merilis aplikasi web sederhana.

Kompetensi Lulusan

  • Merakit, merawat, dan memperbaiki perangkat komputer
  • Merancang dan mengonfigurasi jaringan LAN, WAN, dan wireless
  • Mengelola server dan layanan jaringan berbasis Linux
  • Membangun aplikasi web dengan HTML, CSS, dan JavaScript
  • Menerapkan dasar keamanan jaringan dan troubleshooting
